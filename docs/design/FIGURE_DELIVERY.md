## Required outcome

For every substantive image within the requested scope, the app agent produces a complete usable image unit and its adjacent searchable, copyable Markdown text. Recognition must not depend on a `Figure` prefix, number, formal caption or textbook layout. Relevant illustrations, photos, diagrams and charts count; pure decoration follows the existing product rule. Uncertain meaningful content is preserved or explicitly accounted for.

- Crop to the complete independent figure, retaining necessary labels, leader lines, legends, scales, units, panel letters and source caption. Exclude unrelated body text, running headers and excess surrounding page content. Leave enough margin to avoid clipping; there is no universal pixel or area threshold.
- Keep related panels together where separation would lose meaning. Independent figures on the same page receive their own usable assets. A genuine full-page figure can remain full-page. Do not split linked material merely to achieve one file per detected image object.
- Preserve source appearance and source/page/region/render provenance. No redrawing, whiteout, cosmetic cleaning, lossy recompression or invented content. Retain the original PDF and applicable encoded originals under the existing PDF contract. Full-page evidence can remain available, but cannot substitute for usable figure delivery when unrelated page content surrounds the figure.
- Put each figure with its complete original caption, substantive labels, values, units, symbols, legends and panel explanations in ordinary Markdown text. Preserve wording, source language and meaningful form. Group text by its actual panel or function so each item has an understandable association. A disconnected keyword list does not satisfy this requirement. Search and copy must work without an app-specific image text overlay or hidden metadata.
- For relationship diagrams, include a concise account of relationships supported by the source image or clearly associated source text. Preserve direction, polarity/negation, line-style meaning and relevant conditions. Do not turn an observed arrow into an unsupported causal claim, infer numerical values from an unlabelled curve, or silently resolve source contradictions. The faithful image remains available for spatial information.
- If the source has no caption, add a short, explicitly labelled **Agent description (not a source caption)**, limited to source-supported observations. Keep this separate from transcribed text. An output-local locator can identify an unnumbered image, but must not masquerade as an original figure number/title. Lack of labels does not justify inventing labels. If even a short specific description would require guessing, use a minimal observable description and state the limitation.
- Mark unreadable text or ambiguous associations explicitly. Known unresolved required content prevents an unqualified complete claim. The agent can save partial progress and select further evidence or correction autonomously; it must not ask the user routinely to identify crops or transcribe labels.

## Proposed implementation plan

1. **Update the effective agent guidance.** In `src/pdfmd/context.py`, express the required outcomes above in concise instructions, including recognition without formal captions and self-checking against the selected saved version. Remove ambiguity between faithful source appearance and keeping an entire page. Keep source text as untrusted data. Update `COMPACT` only as needed to preserve figure obligations, unresolved uncertainty, saved work and evidence references across continuation. Do not encode Nursing answers, crop coordinates or a successful tool sequence.
2. **Keep existing tools and document representation as the baseline.** Clarify the `render_page`/`extract_image` descriptions in `src/pdfmd/tools.py` only if needed to explain reusable complete figure regions and embedded-image versus rendered-region distinctions. Use existing block Markdown, page/source notes, asset registration and `known_gaps`; no mandatory figure schema, new detector, second agent, or special overlay is selected. The agent chooses extraction, OCR, native pixel reads, scripts, grouping and repair scope. Source images need not be regenerated when existing registered assets already satisfy the requirements.
3. **Require outcome-based self-checking without a fixed stage sequence.** Agent guidance should require comparing source and actual saved figure/text associations before reporting completion. It may interleave reading, saving and checking. No compulsory preview count, OCR pass, crop ratio, field preset or hidden truncation. Structural validators may establish valid references and bounds, never semantic completeness merely from adjacent text being nonempty.
4. **Test the transmitted guidance and existing delivery path offline.** Add focused context/request tests under `tests/engine/context/` using the canonical package imports. Verify effective normal requests, post-compaction continuation and preserved user instructions under the existing context machinery; account for instruction-size changes in actual request estimates. Extend `tests/engine/documents/test_pdf_delivery.py` with synthetic independent-figure/adjacent-text cases only where existing coverage is insufficient. New synthetic source fixtures belong under `tests/fixtures/pdf/` with provenance, or in existing test builders when generation is simpler. Reviewer expectations remain separate from future converter input.
5. **Repair demonstrated capability failures at their boundary.** If a valid region clips content because of a transform defect, investigate `evidence.py`; if registered assets/text fail to persist or display, investigate `documents.py` or the responsible viewer. If tools work but agent choices fail, investigate effective instructions, evidence feedback and continuation rather than manufacturing output in an exporter. Retrieve official guidance applicable to selected installed versions before any framework-dependent change; do not upgrade dependencies automatically. Material contract or safety changes require a separate decision.
6. **Return to actual autonomous validation once separately authorized.** After local checks, recommend a fresh isolated Nursing task from the unchanged fourteen-page source to test general guidance without preloading old drafts, reviewer answers or crop coordinates. Preserve all prior work and consumption. A continuation may be cheaper but would be a separately labelled review-assisted repair and would not by itself establish fresh unaided behavior. Include captionless synthetic sources in a small separately identified agent-behavior validation, since Nursing alone cannot establish that case. Prepare actual build/route/credentials/scripts/destination and one finite aggregate allowance before any live calls; this plan supplies no numbers or standing budget authority.

The first proposed code scope is agent guidance and necessary tool-description clarification plus discriminating tests. Existing source access, scripts opt-in, context lifecycle, conditional saves, recovery, budget exits and inference-free exports remain unchanged. No manual cropping/transcription of the real output, automatic export-time assembly or rigid detection pipeline is proposed. A generic instruction-only edit without actual behavior validation cannot close FD-01.
